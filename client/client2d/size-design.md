# 尺寸系统（规则与口径）

> **数值唯一源**：`tools/sprite-factory/manifest.json`（每素材一条：模型来源、设计真实尺寸、派生规则）。
> **派生数据**：`client/assets2d/prerendered/derived.json`（derive.py 从 manifest + 工厂 3D 几何生成，提交在 repo）。
> 本文件只保留规则、口径与取舍说明。**逐物件数值表已全部删除，禁止在本文件或其他消费方手加数值。**
> 改尺寸的流程：改 manifest → `python3 tools/sprite-factory/derive.py` → `npm run lint:assets` 验收。

## 1. 术语

| 术语 | 定义 |
|---|---|
| 世界单位 | 地面与布局的单位。1 世界单位 = 地面贴图 3 px（`TPX = 3`）。碰撞盒、坐标、布局占地全用世界单位 |
| 登记宽 $W$ | 一个精灵在世界中的绘制宽度（世界单位）。由 manifest 规则派生，存 derived.json 的 `drawW` / 消费表 |
| 绘制高 | 精灵按登记宽绘制后的画面高度。不登记，由精灵像素宽高比决定 |
| 站姿占地 stance | 3D 模型在地面附近高度截面的投影轮廓（工厂几何派生）。排序、Front 切分、占地、脚锚点一律用 stance，不用全包围盒 |
| 活物 | 人物、生物、道具、树。按真实米数定尺寸 |
| 建筑 | 城堡建筑、商店、布局建筑。按描绘尺寸或占地定尺寸 |

## 2. 工厂标定（实测）

工厂相机：正交，俯角 $40^\circ$，正南向北。精灵密度 $14\ \mathrm{px}$/模型米（像素化后）。

标定方法：工厂 `calibrate()` 渲三个标定物，用不透明像素（alpha>200，排除半透明烘焙阴影）的紧包围盒量像素跨度。原生渲染密度 $48\ \mathrm{px}$/米。

| 常数 | 实测 | 理论 | 说明 |
|---|---|---|---|
| 宽 $G$ | $14\ \mathrm{px}$/米 | $14$ | 水平方向不压缩 |
| 竖直 $V$ | $10.7\ \mathrm{px}$/米 | $14\cos40^\circ = 10.72$ | 竖直边在画面里缩短 |
| 深度 $D$ | $9.0\ \mathrm{px}$/米 | $14\sin40^\circ = 9.00$ | 地面深度边在画面里缩短 |

一个物体的画面投影高（模型米）：$\mathrm{projH} = H\cos40^\circ + D\sin40^\circ$。宽不压缩：画面宽 = 真实宽。

地面没有独立的米制：精灵的模型米只经登记宽进入世界。两套米在派生表处汇合，不直接比较。

## 3. 绘制规则

每类物件只用登记宽绘制：$k = \dfrac{W \times \mathrm{zoom}}{w_{px}}$，绘制高 $= h_{px} \times k$。精灵在同一俯角下渲染，宽高比自带投影。定宽即定高，比例自洽。

派生规则（derive.py 单点实现，manifest 逐条声明）：

| 规则 | 公式 | 适用 |
|---|---|---|
| live-height | $(\mathrm{设计}H\cos40^\circ + \mathrm{设计}D\sin40^\circ) \times U_{LIVE} \times$ 精灵宽高比 | 高锚活物（多数生物、人物、树、特快） |
| live-width | $\mathrm{设计}W \times U_{LIVE}$ | 宽锚活物（扁平生物、翼展生物） |
| struct-width | 描绘宽 $\times U_{STRUCT}$ | 建筑与布局物件 |
| pin | manifest 钉版值 | 构图锚、可见性下限、场地折中（逐条带理由） |

已删除的旧口径：建筑放大系数（占地 ×1.8）、生物身高系数（$h_M \times 20$）、地标逐个拍 `visualW`、FOOT 手抄占地表、sprites.json 手注 footOffset、renderer 内 FIGURE/CREATURE 手抄表。全部改为派生。

## 4. 两条尺度

| 尺度 | 值 | 适用 | 锚点 |
|---|---|---|---|
| $U_{LIVE}$ | $5$ 世界单位/真实米 | 人物、生物、道具、独立树 | 巫师（1.8 米身 + 0.65 米帽 → 绘制高约 10.7） |
| $U_{STRUCT}$ | $3.2$ 世界单位/模型米 | 建筑（模型描绘尺寸换算时） | keep 与礼堂 |

活物放大 5 倍是游戏化比例（星露谷同类口径：农夫与一层小屋同量级）。本游戏同理：巫师与一层商店同量级，城堡与巨怪保持压倒量级。

命名商店（村庄与村外）是实例级钉版：登记宽 = 服务器占地宽（OBSTACLES 盒宽），不走精灵派生表。

**历史漂移记录（已由派生消除，留作口径说明）**：

| 漂移 | 旧状 | 现状 |
|---|---|---|
| 建筑倍率双轨 | 车站/图书馆/宿舍塔/温室按 ×3.7 登记，住宅按 ×3.2，文档统称 U_STRUCT | 统一 ×3.2 派生，四件绘制宽相应缩小约 11–13% |
| hoops/dock「12 米」 | 文档称展开 12 米，模型实宽 4.7/3.4 米 | 改实测 + pin 36（球场构图），文档虚构值作废 |
| 住宅 lot 盒 | FOOT 76/100 旧单位遗留，视觉与碰撞差 5 倍 | FOOT 改 stance 派生；lot 语义只保留给场地类（见第 6 节） |
| 脚偏移参照 | footOffset 拿全包围盒南缘当参照，手量 18 条（龙 −12.7 等） | 改 stance 南缘参照几何派生：多数归零，剩 4 条真残差 |

## 5. 站姿占地与脚锚点（几何派生）

定义（derive.py + 工厂 `stanceGeometry`）：

| 量 | 定义 |
|---|---|
| 地面带 | 模型 bbox 底以上 $\mathrm{clamp}(0.28 \times 总高,\ 0.08,\ 0.6)$ 米 |
| stance | 地面带内几何（顶点 ∪ 与带相交的网格包围盒）投影到地面的 x/z 跨度；s/n = 相对原点的南/北缘 |
| footOffset | 精灵 alpha 底行（alpha>200）−（anchorY + stance 南缘 × $G\sin40^\circ$)，单位精灵 px |
| 接触带 | bbox 底以上 $\max(0.04,\ 0.06 \times 总高)$ 米，定脚接触南缘 |

口径要点：

- 排序键 = 站姿南缘；Front 切分线 = 站姿北缘；占地深度 = stance 跨度。包围盒（含尾/颈/翼高位部件）只作尺度换算基准，不再决定占地。
- footOffset 只对生物与人物帧派生；$|\mathrm{offset}| \le 2$ px 不登记。飞行/漂浮 5 种（摄魂怪、pixie、凤凰、雷鸟、鸟群）悬空是设定，豁免登记，仍画地面投影。
- 人物全帧派生偏差均 $\le 2$ px，无登记项——结论与 2026-10-22 手量审计一致。

## 6. 占地与碰撞

占地（layout2d FOOT）由派生表 `layoutKinds[*].foot` 提供，两种模式在 manifest 逐 kind 声明：

| 模式 | 定义 | 适用 |
|---|---|---|
| stance | 站姿占地 × 绘制尺度 × 1.1 余量（0.5 取整） | 有实体占地的物件（住宅、井、帐篷、船、温室等） |
| lot | 场地/间隙盒，值在 manifest 声明（lotFoot） | 商店地块、球场记分牌场、路灯间隙、栈道等 |

服务器建筑碰撞（`buildingColliders2D`）由 FOOT 自动生成（横向内缩 6%、北侧内缩 12% 的既有口径不变）。

已知口径与例外（lint PENDING，待拍板）：

| 项 | 口径 |
|---|---|
| 禁林树干盘 | 服务器 145 个碰撞盘，站立视觉只覆盖选点 17 个；128 个无视觉——补视觉/删碰撞/保留例外三选一，未拍板前 lint 只报数 |
| 装饰树 | 村庄定点树、林缘疏林带、庭院橡树有视觉无碰撞：全图既有口径，登记为例外类 |

| 大礼堂 | 无独立盒，城堡区由 keep 盒与塔盒覆盖，接受 |

| 海格小屋 | 精灵与布局石屋同体，碰撞由石屋 placeExact 盒（24×16）覆盖主体，南侧门前空地故意不设碰撞 |

## 7. 接触阴影

| 项 | 口径 |
|---|---|
| 贴图 | 预烘焙 128 px 径向渐变，全活体共用，逐帧只缩放绘制 |
| 透明度 | 中心 alpha 0.34，边缘衰减到 0 |
| 宽度 | 登记宽 × 0.8；高度 = 宽度 × 0.646（地面深度压缩） |
| 位置 | 中心 = 锚点，在实体排序槽内、本体之前绘制 |

精灵自带的工厂烘焙阴影在像素化后只剩淡色污渍且偏侧，不再承担接地功能。

## 8. 模型比例标记

lint 对生物/建筑/树三类比对模型宽高比（几何包围盒，无阴影污染）与设计宽高比，偏差 >15% 标记（derived.json `flag`、lineup ⚠）。标记只登记不阻塞：模型重做归工厂线。

当前重点标记（全表见 lint 输出）：巨怪（宽扁，+75%）、商店模型 houseWood/houseStone（矮胖，+52%/+38%，设计意图 8×7×5）、橡树 treeRound（冠窄，−72%）。特快因模型朝向（画面宽为车长与车深混合投影）豁免宽高比标记。

打人柳：设计冠径 10 米、高 9 米，按 $U_{LIVE}$ 应登记约 50；现 pin 30 为场地折中（50 会盖满柳树场地并压到湖岸与林缘路）。待裁决：扩场地或维持 30。
