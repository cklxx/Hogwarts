# Ivy Moss 新手体验报告（操作49次）

## 1. 时间线
- 第一次走动：操作2，摇杆向上，立刻从夜晚街道切到白天草地。
- 第一次施法/打中：操作4，锁定小精灵后点快捷栏1，命中24→15，头顶飘「Stupefy!」白字、紫色粒子炸开、血条掉格。
- 第一次「反应」：全程没看到。只见过紫粒子和伤害数字，没见过湿/冻/蒸汽文字或特效（冰弹模板没来得及铸造就被打断）。
- 第一次打倒魔物：没做到。唯一打伤的小精灵（24→15）随后被人群冲散，锁定跳到玩家身上，之后再没能稳定锁住怪。

## 2. 前30秒
打中反馈清楚：咒名文字+粒子+血条+数字都有，知道打中了。但奖励弹窗不暂停战斗，读符文说明时被贴身小精灵活活打到0/100，开场20秒就死了一次，很挫败。

## 3. 卡住/看不懂
- 操作4-6（符文弹窗）：弹窗时仍挨打，且弹窗X第一次点屏幕外、第二次才中。
- 操作11（大礼堂）：教程「打开」按钮点了没反应，最后自己按咒语书图标才进去。
- 操作13-21（咒语书）：每次开书强制弹「元素弹」模板，X连续3次点不中；关掉模板=整本书一起关，根本找不到Tempus。后来乱点顶部沙漏才是时间显现，教程5/7完全没提示这点。
- 操作37-47（锁怪）：瞄准键在玩家堆里反复锁到巫师/麻瓜，且锁怪后目标会自动跳到身边玩家，导致操作38误伤玩家Keeper Four（飘9伤害）。教程教的就是「点瞄准再放1」，没有区分敌友的提示。

## 4. 视角
俯视看得清路；夜里画面很暗，怪和玩家挤在一起时名牌、血条、红圈重叠，小精灵体型小被人挡住看不见。

## 5. Bug
- 奖励/符文弹窗不暂停战斗 → 读说明时被打死，期望弹窗暂停或无敌。
- 锁怪后目标自动切到附近玩家 → 安全区外攻击真的生效打伤玩家，期望锁定只在魔物间循环或有友军保护。
- 教程4/7「打开」按钮无响应，期望它直接打开咒语书。
- 元素弹弹窗X热区疑似偏小，多次点击无反应。

## 6. 最想继续 / 最想关掉
- 最想继续：攒蓝在没人的路上单杀一只小精灵，看它倒下和掉落。
- 最想关掉：操作13-21在咒语书里反复关不掉弹窗、又找不到教程要的咒语那五分钟。
