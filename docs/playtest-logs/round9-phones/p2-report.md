# Leo Park 新手体验报告（约20分钟，42个操作）

## 1. 时间线
- 第一次走动：op3，推摇杆向上，夜晚切白天，走到石板路口。
- 第一次施法：op5，锁定康沃尔郡小精灵后按 1 号格。
- 第一次打中效果：op5，魔弹命中，精灵头上飘紫色「滑倒！」和数字 14，血条变短。
- 第一次看到「反应」：op5，就是「滑倒」。之后 op21 还看到别人的冰蓝色护罩特效。
- 第一次打倒魔物：没有。全程未亲手打死任何魔物，唯一打中的精灵之后脱离视野。

## 2. 前 30 秒
走动跟手，命中立刻有飘字（14）+ 状态词（滑倒）+ 血条变化，反馈清楚，知道打中了。这是全程手感最好的一段。

## 3. 看不清 / 点不准 / 卡住
- op6-8：符文弹窗按钮连点 3 次才中，截图分辨率和触摸坐标不一致，按钮看着大其实点边缘无反应。
- op10-12：教学「去大礼堂 · 带我去」，点了多次没反应，以为卡住；实际只给方向箭头，不自动寻路。
- op13：刚走到路口，无预警被 5 只摄魂怪围殴秒杀，教学才 3/7，我没有任何对抗手段。
- op15-18：黑湖蓝水面和石板路在夜里边界不清，两次误走进湖。
- op21-35（最严重）：教学 5/7「施放时间显现」让打开咒语书，书每次自动弹出「元素弹」模板挡住咒语列表，列表里的 Tempus 根本点不到；在里面卡了十几步，还误铸了一个冰元素弹。最后 op36 才发现施放入口是屏幕顶部的沙漏图标，与引导完全不符。

## 4. 视角
俯视斜角能看清角色周围约一个屏幕，没有被 UI 挡住目标的情况。问题是夜晚光照太暗，黑湖岸线、路口方向难分辨，找路靠瞎走。

## 5. Bug
- 做了什么：按引导在咒语书里找时间显现并铸造 → 看到元素弹模板霸屏、Tempus 不可点 → 期望：引导应直接指向顶部沙漏或在书里高亮 Tempus。
- 做了什么：新手村路口停留几秒 → 被世界事件摄魂怪秒杀 → 期望：教学期安全区或提前预警。
- 做了什么：点「带我去」→ 角色不动 → 期望：要么传送/自动寻路，要么不要做成按钮样式。

## 6. 想继续 / 想关掉
最想继续：带着分裂符文和新铸的冰弹出安全区打一群精灵，看冰冻+分裂组合的反应。最想关掉的一刻：op21-35 在咒语书里反复关弹窗、找不到「时间显现」的时候。
