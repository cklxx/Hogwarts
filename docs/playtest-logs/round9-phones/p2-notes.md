- op1 看：入学通知书界面，填名字+选学院（让帽子决定/格兰芬多/赫奇帕奇/拉文克劳/斯莱特林/不要斯莱特林），红按钮"登上霍格沃茨特快"。

- op4 点tb-tab瞄准：锁定敌对小精灵（10/24血，8米），顶部出现红色目标条。

- op6-8 装符文弹窗点了3次才中（截图472宽/逻辑390，比例1.21，坐标换算坑）。
- op9 符文"分裂"装到昏昏倒地成功。
- op10-12 "带我去"点多次不自动寻路，只给方向箭头。
