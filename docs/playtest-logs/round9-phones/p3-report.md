# Nina Gale 试玩报告

## 1. 时间线
- 第 4 个操作：第一次走动（摇杆向上）。
- 第 6 个操作：第一次施法与第一次打中，昏昏倒地打康沃尔郡小精灵，目标卡 24→10。
- 打中画面：头顶冒出红色小伤害数字，目标卡血量变化，魔弹本身很小、飞过几乎看不清。
- 「反应」：第 39 个操作锁定的小精灵带「🌿 定身」；画面上见过别的巫师喊「呼呼不痛！」「融化！」字样。自己的冰弹没铸造成，没亲手打出湿/冻/蒸汽。
- 第一次打倒魔物：没有。第一只打到 7/24 后跑出 45 米丢了，第二发魔弹锁到了玩家身上。

## 2. 前 30 秒
打中东西的反馈偏弱：只有目标卡数字和小伤害字，没有明显受击动作或音效提示。血量数字本身清楚。

## 3. 卡住/点不准
- 操作 7-9：符文弹窗红按钮连续点偏，实际位置比看着靠上。
- 操作 14：教程「打开」按钮点了完全没反应，改点咒语书图标才进。
- 操作 24/32/35：元素弹模板点「铸造」「施放」毫无反馈，6 号格始终是荧光闪烁，不知为何（可能「躺平了」状态，但无任何提示）。
- 操作 41/46：按瞄准总锁到身边玩家而非魔物，第 41 操因此误射一名玩家一发。

## 4. 视角
俯视镜头基本看得清，但顶部提示横幅和目标卡常挡住正前方魔物；人群扎堆时名字和血条互相叠住。

## 5. Bug
- 造咒语时点「铸造」无反应、无报错，退出后快捷栏没变。
- 瞄准时魔物在前方却切到 2 米内玩家，还带着敌对红圈，容易误伤。
- 咒语书打开期间仍在被攻击（血掉到 93），书界面没有暂停或保护。

## 6. 最想继续 / 最想关掉
最想继续：把冰元素弹铸造成，冻住一只小精灵看反应。
最想关掉：在咒语书里反复点「铸造」没任何反应、还隔著书挨打的那一刻。
