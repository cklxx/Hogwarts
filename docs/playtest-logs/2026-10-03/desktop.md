# 桌面真实浏览器试玩：DesktopRowanLow（2026-10-03）

## 方法与限制

使用 Chromium + Playwright 真正加载 http://127.0.0.1:7777/，从网页填名字入学；只使用页面鼠标点击、W/Tab/数字键/B/F/M/Esc，没有写入游戏状态、没有直发 WS 指令、未读出或打印任何密钥。脚本 `/tmp/hogwarts-desktop-play.mjs`，日志 `/tmp/hogwarts-desktop/actions.jsonl`，截图 `/tmp/hogwarts-desktop/s001.png` 至 `s022.png`。最初 DesktopRowan 在1280×800默认画质入学，但截图连续30秒超时，关闭重开 DesktopRowanLow 使用 ?q=low，1100×700后降至900×600。此时多浏览器 SwiftShader 软件渲染+formal/tests共用CPU，不能把耗时当作真实硬件帧率。截图与DOM文字有数秒时间差；文中不根据缺少瞬间toast否定操作。
