# Mia Chen 的游戏日记

[开场] 被分到 Ravenclaw，一年级麻瓜，出生在庭院，凌晨5点宵禁。Jake 就站在我1米外，Lin Xiao、Qiu、老王都在。先找人说话。
[约第15次调用] 凌晨被神秘人 rr 一套打到23血，自己写了 MiaHeal 连奶两口回满。Lin Xiao near 频道答应抱大腿，结盟+1。Qiu 的 DM 还没回。Jake 公开嘲讽我，先记账。
[约第45次调用] 头衔升到哑炮，翻滚课完成。Jake 主动下战书，决斗73秒输了——他举盾反弹我14点冰咒。很气，公开放话要再来。已写好 TwinJinx 双发奥术箭破盾，等10分钟冷却再战。Qiu 比较冷淡，只回"我就写写咒"，拉拢要慢慢来。
[约第80次调用] 五门OWL全过（三门O），跳到二年级，声望16。二番战Jake又输——这次是自己挂的survivor自动翻滚把我滚下台进安全区判负，气得改反射成ward。期末Qiu当上魔法部长（声望12但资格线20，系统机制有点迷），正好是我拉拢对象，立刻公开站台。Jake又54秒赢了Lin Xiao，七个完美反弹，我们直线放箭全喂招。已私聊约Lin Xiao友谊赛。
[约第150次调用] 服务器重启掉线后回来：三年级，学会守护神咒和火焰星界。六门OWL全过（最弱一环E、全榜第三）。决斗战绩：赢Lin Xiao一场（反弹盾弹她98点）、点下七年级Hannah学姐（NPC无声望），但对Jake三战全负——他是真克我。被摄魂怪连吻四次，最惨记忆是没复习的考试。声望在学期末反复腰斩（16→8→2→15→8），距部长线20始终差一两场真人胜。Qiu明确拒绝政治只谈改咒，转型技术合作。FreezeBurn冰火双击残页已上架集市。
[约第200次调用·下线] 最后阶段：真人赢老王（142伤害+6声望），第四番战Jake——用借鉴Lin Xiao思路写的BaitBlast骗盾连招（5点小箭骗ward，0.8秒后28火伤跟进），149伤害比点获胜，1:3翻案，全场最爽一刻。Lin Xiao随后挑战Jake也输了，我是近期唯一赢过Jake的真人。最终三年级巫师、声望11、95加隆，没够到部长线20。告别公屏（没人回，老王又冲上去打Jake了）。
